# Локальный дневник

Версия 1.1.0. Заметки, секреты, флешбеки, кодекс и меморибук текущего чата. В промпт попадает только то, что отмечено. Сборка памяти идёт моделью клиента и только по кнопке.

Из кода расширения наружу ничего не уходит. Кнопка обновления в Таверне — это её `git pull` этого репозитория.

## Установка в SillyTavern

Кнопка обновления есть только у установки из git.

1. «Расширения» → «Установить расширение».
2. Адрес: `https://github.com/Prohor-godslayer/local-diary`. Ветка `main`.
3. В «Управление расширениями» карточка «Локальный дневник», версия 1.1.0.
4. Включи «Уведомлять об обновлениях расширений», если пункт есть.

Кнопка 📕 у края чата. Пункт меню — «Локальный дневник».

Папку без git в `data/<пользователь>/extensions/local-diary` удали и поставь по ссылке, иначе Таверна не увидит новые коммиты.

### Когда Таверна говорит, что нужно обновить

`"version": "1.1.0"` и `"auto_update": true`. Таверна сравнивает коммит с `origin/main`. Кнопка на карточке по-английски называется **Update available**, по-русски — перевод из языкового пакета. Нажатие делает `git pull`. Номер после обновления смотри в карточке.

## Установка в Tavo

1. Скачай `tavo/local-diary.tpg`: https://github.com/Prohor-godslayer/local-diary/blob/main/tavo/local-diary.tpg
2. Импортируй плагин. Сетевого права нет. Нужны ввод, сообщения, переменные, файл и генерация.
3. Открытие: кнопка 📕, действие ввода «Локальный дневник», боковая панель.

Следующую версию ставь новым импортом `.tpg`. Версия плагина 1.1.0.

## Как пользоваться

Дневник привязан к чату. Другой чат — другая книга.

1. Заметки, секреты, флешбеки и кодекс: открой раздел, впиши текст, при необходимости название, нажми «Добавить». Крестик удаляет строку.
2. У кодекса есть тип: человек, место, вещь, правило.
3. Меморибук. «Собрать из чата» берёт последние реплики и просит модель выписать 4–8 фактов. Пока идёт сборка, не отправляй новое сообщение в чат. Потом отметь строки черновика и нажми «Оставить отмеченное». Строки со словами «промпт», «модель» и «ассистент» в книгу не попадают.
4. «Что отдавать в промпт». По умолчанию включены секреты и меморибук. Флешбек, заметки и кодекс выключены, пока не поставишь галочку. «Сохранить» сразу меняет кусок, который клиент увидит перед следующим ответом.
5. «Скачать файл» пишет JSON этого чата на диск. «Вложить файл» заменяет книгу чата содержимым файла. Так дневник переносится между устройствами.

Кодекс без галочки остаётся только у тебя на экране. С галочкой персонаж может на него опираться.

## Где лежат данные

SillyTavern: метаданные текущего чата, `local_suite.diary`. Tavo: файл `lx_diary_chatbag` по id чата, плюс запасные копии в переменной и `localStorage`.
