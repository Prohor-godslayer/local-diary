# Локальный дневник

Заметки, секреты, флешбеки, кодекс и меморибук текущего чата. Меморибук собирается кнопкой из последних сообщений через модель клиента. Секреты и память по умолчанию попадают в промпт. Заметки и флешбеки выключены, пока вы их не включите.

Файл дневника хранится вместе с чатом. Есть выгрузка и загрузка JSON.

## SillyTavern

Скопируйте репозиторий в `data/<пользователь>/extensions/local-diary`. Панель: кнопка у края чата и пункт «Локальный дневник».

## Tavo

Импортируйте `tavo/local-diary.tpg`.
